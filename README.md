# Graviton Publications Hub

Publication record and artifact index for the Graviton Research Group.

The hub tracks every peer-reviewed paper produced by the group together with the
artifacts that accompany it: code, datasets and demo systems. Artifact links are
published only for artifacts that are publicly available.

## Layout

- `docs/` - publication metadata, checklists and editorial notes
- `scripts/` - small utilities used to regenerate the public site
- `site/` - static site sources

## Contributing

Publications are added by the programme office after each acceptance notification.
Code links are curated separately and must point to the canonical upstream repository.
